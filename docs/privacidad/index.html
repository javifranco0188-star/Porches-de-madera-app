Política de privacidad

Porches de Madera Baratos

Esta política explica el tratamiento de la información utilizada por la aplicación Porches de Madera Baratos.

Datos que puede facilitar el usuario

La aplicación puede solicitar datos necesarios para atender consultas, solicitudes de presupuesto, reservas o comunicaciones, como nombre, teléfono, correo electrónico, dirección, información incluida voluntariamente en mensajes y fotografías seleccionadas por el propio usuario cuando utilice funciones que permitan adjuntar imágenes.

Finalidad

Los datos se utilizan únicamente para gestionar las funciones solicitadas por el usuario, responder consultas, preparar presupuestos, gestionar solicitudes y prestar los servicios relacionados con la aplicación.

Imágenes y archivos

Cuando el usuario decide seleccionar una fotografía o archivo desde su dispositivo, el acceso se utiliza únicamente para la función solicitada. La aplicación no accede a imágenes que el usuario no haya seleccionado voluntariamente.

Servicios técnicos

La aplicación puede utilizar servicios de infraestructura y almacenamiento necesarios para su funcionamiento. La información se trata únicamente en la medida necesaria para prestar las funcionalidades de la aplicación y mantener su seguridad.

Conservación y derechos

Los datos se conservarán durante el tiempo necesario para atender la solicitud correspondiente y cumplir las obligaciones legales aplicables. El usuario puede solicitar información, rectificación o eliminación de sus datos mediante los canales de contacto disponibles en la aplicación o en la web oficial del servicio.

Menores

La aplicación está destinada a usuarios que buscan información y servicios relacionados con porches y trabajos de madera y no está diseñada específicamente para menores.

Cambios

Esta política puede actualizarse cuando cambien las funcionalidades de la aplicación o los requisitos legales y de las plataformas de distribución.

Última actualización: 5 de septiembre de 2026.
